# Промпт для внешнего агента

## Задача

Предложи 2–3 варианта интерфейса игровой визуализации производства.

Нужно показать в движении:
- как заявки приходят на вход;
- как из них появляются партии;
- как детали идут от участка к участку по маршруту;
- как они задерживаются в очередях между участками;
- как решение руководителя меняет порядок.

Тема — тёмная, спокойная, без «хорошо/плохо» цветом. Цвет не оценивает, он только различает состояния (ждёт / работает / закрыто / новое).

## Входные материалы

1. `GAME.md` — краткое описание игры и асимметрии.
2. `TRACE-EXAMPLE.json` — пример следа прогона (структура реальная, числа модельные).
3. Спека следа: события на каждое значимое изменение + кадры на границах смен. Формат один и для файла, и для `GET /v1/sessions/:id/trace`.

## Ограничения

- Не показывай цех на главном экране руководителя. Цех — только в разборе.
- Не добавляй баллы, рейтинги, зелёный/красный.
- Не выдумывай причины задержек, которых нет в следе.
- Времена модельные. Структура — предметная.
- Интерфейс должен уметь проигрывать след по времени (play / pause / перемотка по сменам).

## Что вернуть

Для каждого варианта:
- краткое название и идея;
- что видно на главном экране;
- что видно в режиме «производство в движении» (разбор или отдельный слой);
- как показаны очереди и пролёживание;
- как показано появление новой заявки;
- один схематичный макет (описание или ASCII/wireframe).

Не пиши код. Сначала варианты.
