## Why

Симулятор сейчас — набор TypeScript-модулей, которые запускаются тестами. Игровой цикл руководителя не интерактивен: чтобы увидеть смену, нужен `npm test`. Строить React-экран прямо на модулях опасно — интерфейс руководителя сложный, представлений будет несколько (главный экран, слой цеха для разбора, рабочие места ролей, отладочный вид), и каждое изменение UI будет тянуть правки ядра.

Нужен стабильный HTTP-контракт, через который любой клиент — React, CLI, тесты — создаёт прогон, получает срез, отдаёт решения и продвигает смены.

## What Changes

- Появляется серверный каталог `SIM/api/` — Fastify на `localhost:3400`, сессии в памяти.
- HTTP для управления сессией и снимков, WebSocket для шага смены.
- Срез на границу смены считается **перепрогоном с отсечкой**, а не выборкой из финальных записей (см. `sim-priority-decision`, D3).
- Три среза видимости (`shop` / `roles` / `summary`) отдаются через существующий контракт `SIM/contract/slices.ts`; срез цеха — только по явному запросу.

Не меняется:

- Правило «plant не импортирует system и наоборот» — сервер только читает результаты прогона.
- Схема событий версии 1.
- Ёмкости, длительности маршрута, `CONTRACT_STAND` (значение горизонта остаётся 12), MTBF.

Меняется в ядре (минимум, без которого API не работает):

- `runStand` получает горизонт аргументом вместо чтения `CONTRACT_STAND.horizonShifts` в 7 местах.
- `contract/boundary.ts` учит зону `api`: проверка импортов сейчас её не знает и пропускает импорт из `plant/` в `api/` молча.

## Capabilities

### New Capabilities

- `sim-api`: сессии прогона, HTTP-снимки, WebSocket-шаг смены, приём решений, три среза видимости.

### Modified Capabilities

- `plant-engine`: горизонт прогона становится аргументом `runStand`, значение по умолчанию — стенд.

## Impact

| Файл / каталог | Воздействие |
|----------------|-------------|
| `openspec/changes/sim-api/` | это изменение |
| `SIM/api/` | новый каталог сервера |
| `SIM/run/run.ts` | горизонт аргументом, срез по смене |
| `SIM/contract/boundary.ts` | зона `api` и запрет импорта в неё из ядра |
| `SIM/package.json` | зависимости Fastify, скрипт `npm run api` |
| `SIM/tsconfig.json` | `SIM/api/**` в `include` |
| `SIM/test/` | проверки горизонта аргументом и границы с `api` |
| порт 3400 | 3010 занят Kosmos Panel, 3000–3002 и 3006 тоже заняты |
