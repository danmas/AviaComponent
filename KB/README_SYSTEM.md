# ИАС «Альфа-Пром»: система, данные, модули

**Актуализация:** 2026-11-25

> **Источники:** `Общее описание системы Альфа-Пром (октябрь 2026г).pdf`, `Паспорт базы данных и серверной части…pdf`, `ИТ-процессы по этапам технологического процесса…pdf`, `ТЗ Альфа-Пром — Приложение 1 (б).pdf`

## Назначение и охват

Система сопровождает каждую позицию заказа: письмо заказчика → КД → технологическая подготовка → нормирование → планирование → производство → ОТК → склад ГП → отгрузка. На участке ЧПУ — до станка (пилот FOCAS2/OPC UA).

В единой базе работают: руководство, коммерческая служба, ПДО, технологи, нормировщики, мастера участков, ОТК, снабжение, склад. 58 учётных записей, 17 ролей, 110 рабочих в справочнике.

**Резервное копирование:** ежедневная полная копия БД и файлов, копия БД каждые 30 минут, копии изменяемых строк перед распространением ТП на партии.

### Станки с ЧПУ (пилот)

Считывание данных со стоек **без управляющих воздействий**: программы, пуск и корректоры не изменяются. Цеховой шлюз опрашивает станки каждые 0,5 с, передаёт состояние раз в секунду.

Данные FOCAS2 (Fanuc): режим, состояние, координаты, подача, обороты, номер программы, кадр, аварии.
Данные OPC UA (SINUMERIK): то же + нагрузка шпинделя, активный инструмент, время цикла, счётчики.

Анализ управляющих программ → техпроцесс: машинное время ±10–15%, операционная карта 70–75%.

Все функции — **работает в пилотном режиме** (9 станков в справочнике `cnc_machines`).

## Жизненный цикл детали (ядро)

```
Заявка → Сборка → Деталь → Партия (запуск)
                              ├─ Деление партии / отрывная карта (копия карточки + часть количества)
                              ├─ Операции цеха (выполнено / брак / принято)
                              ├─ Приёмка ОТК (образец + серия)
                              ├─ Окончательный контроль (брак → ведомость дефектов)
                              ├─ Склад ГП (выполнено = оприходовано, принято = отгружено)
                              ├─ Комплектование (передача в сборку)
                              └─ Отгрузка заказчику → Архив заявки
```

Связи защищены: деталь нельзя удалить, пока есть дочерние; операцию нельзя удалить, пока на неё ссылаются детали; деталь с ведомостью дефектов или историей количества удалить нельзя.
