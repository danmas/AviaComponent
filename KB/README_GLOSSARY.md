# Глоссарий предметной области

**Актуализация:** 2026-11-25

Термины, аббревиатуры и внутренние обозначения, встречающиеся в документах проекта. Сгруппированы по темам.

## Организация и роли

| Термин | Значение |
|--------|----------|
| **ООО «Альфа-Пром»** | Предприятие-владелец ИАС «Альфа-Пром»; изготовление деталей и узлов для авиастроения |
| **AviaComponent / Авиакомпонент** | Внутреннее название проекта анализа (по папке) |
| **ИАС** | Информационно-аналитическая система |
| **ПДО** | Планово-диспетчерский отдел — планирование производства, сверка плана с датами поставки |
| **ОТК** | Отдел технического контроля — приёмка деталей, ведомости дефектов |
| **ДСЕ** | Деталь и сборочная единица; «в ДСЕ» — статус заявки в проработке |
| **КД** | Конструкторская документация (чертежи, 3D-модели) |
| **ТП** | Техпроцесс — маршрут операций изготовления детали |
| **ПЗ** | Подготовительно-заключительное время (наладка, входит в норму) |
| **ПЗВ** | Пролеживание (межоперационное ожидание) в часах |
| **ПКИ** | Покупные комплектующие изделия |
| **НЗП** | Незавершённое производство / незаконченный задел |

| **ТОиР** | Техническое обслуживание и ремонт оборудования |

| **APS** | Advanced Planning & Scheduling — продвинутое планирование с конечными ресурсами |
| **MES** | Manufacturing Execution System — система исполнения производства |
| **PLM** | Product Lifecycle Management — управление жизненным циклом изделия |
| **FAI** | First Article Inspection — контроль первой детали по авиационным требованиям |
| **ISA-95** | Стандарт интеграции корпоративного и производственного уровней |

## Единицы измерения

| Термин | Значение | Важно |
|--------|----------|-------|
| **н/ч** | Нормо-час — единица нормативной трудоёмкости | **Смешивается** с станко-часами и календарными часами — риск противоречия 11 |
| **станко-ч** | Машинное время, занимающее оборудование | Не равно н/ч |
| **чел.-ч** | Фактические трудозатраты исполнителей | |
| **печь-ч / цикл** | Время и количество садок в печи | Термообработка планируется садками |
| **садка** | Загрузка печи на один цикл; срок — одни сутки | |

## Производственные объекты

| Термин | Значение |
|--------|----------|
| **Заявка** | Заказ от письма заказчика до отгрузки; статусы Черновик → В ДСЕ → В производстве → Архив |
| **Позиция** | Деталь или сборочная единица в составе заявки |
| **Партия** | Технологическая единица запуска детали; делится на отрывные карты |
| **Отрывная карта** | Выделение части партии в отдельную карту по 3 основаниям: создание партии, ведомость дефекта, ручной отрыв. **Не уменьшает** количество родителя при отрыве по ведомости |
| **Сопроводительная (маршрутная) карта** | Документ сопровождения партии: 4 блока на операцию (технология, производство, контроль, итоги), печать с QR |
| **Операция маршрута** | Один шаг техпроцесса по детали |
| **Событие движения** | Запись в истории: запуск, выполнение, приёмка, передача, деление |
| **Задел** | Излишки склада ГП и незавершённые детали, снятые с участка (с указанием операции) |
| **Давальческие** | Детали/сырьё заказчика; «Сырьё: Д» — своя деталь из давальческого сырья |
| **Кооперация** | Внешняя обработка (гальваника — АО «Кооператор-1», АО «Кооператор-2»); термообработка на стороне |
| **Отрыв** | Операция выделения части партии |
| **Участок** | Производственное подразделение; тип ресурса: станки / печи / персонал / кооперация |

## Показатели и расчёты

| Термин | Значение |
|--------|----------|
| **Мощность (паспортная / календарная / доступная / свободная)** | Разные понятия: техническая возможность / с учётом смен / без плановых остановок / за вычетом принятых обязательств |
| **Загрузка** | План / мощность × 100%. Заполнение планом имеющегося времени, **не** весь спрос |
| **Очередь** | Оставшаяся работа, готовая к исполнению и не поставленная в период |
| **«Не готово»** | Работа с невыполненными условиями запуска (материал, КД, предыдущая операция) |
| **Плановая готовность** | Прогнозируемая дата завершения детали; пересчитывается по событиям |
| **Производственный дефицит** | Количество − отгружено − склад ГП |
| **Общий дефицит** | Количество − отгружено |
| **Переналадка (А→Б)** | Время от последней годной детали А до первой годной детали Б; может отличаться от Б→А |
| **Пул ОТК** | Очередь партий на приёмку; ёмкость = число контролёров × длительность смены |
| **Реестр достоверности** | Блок экрана: для каждого показателя — где вносится, заполненность, причина пробела, кто закрывает |

## Категории анализа (методология)

| Термин | Значение |
|--------|----------|
| **Подтверждено** | Отображение/расхождение зафиксировано по документу или снимку. **Причина в коде не установлена** |
| **Ограничение** | Методологическая проблема определения или представления, не дефект |
| **Гипотеза** | Сценарий возможного отказа, требует выгрузки для проверки |
| **Прямое противоречие** | Несовместимые утверждения в документах |
| **Неподтверждённая возможность** | Недостаточно доказательств |
| **P0 / P1 / P2** | Шкала экспертного отчёта: риск недостоверного обязательства / значимое ограничение / редакционная сверка |
| **П1 / П2 / П3** | Шкала отчёта по статистике: проверить до использования / устранить для контроля / улучшить интерпретацию |
| **Gate 1 / Gate 2** | Контрольные точки: пригодность планировщика / разрешение использовать сроки для КП |
