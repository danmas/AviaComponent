## Кодировка снимков (отчёт по статистике)

Отчёт `Analiticheskiy_otchet__2026-11-22.docx` использует отдельную кодировку для трёх фотографий экрана «Обзор производства»:

| Код | Файл | Использованные области |
|-----|------|------------------------|
| **И1** | `photo-01.jpg` | Верхние карточки, мощности и загрузка, начало итогов смены, подготовка заявок |
| **И2** | `photo-02.jpg` | Окончание итогов смены, заявки и причины задержек, начало блока достоверности |
| **И3** | `photo-03.jpg` | Продолжение заявок, полный блок достоверности данных |

> ⚠️ **Внимание при цитировании:** коды И1–И3 имеют **два разных значения** в зависимости от документа. В экспертном отчёте И1 = ТЗ, И2 = Общее описание, И3 = Паспорт БД. В отчёте по статистике И1–И3 = три фотографии экрана. Всегда смотри, из какого отчёта ссылка.

В папке проекта снимки сохранены как `Текущий вариант экрана1.jpg`, `экрана2.jpg`, `экрана3.jpg` (состояние на 20.11.2026). Соответствие исходным именам `photo-01.jpg` требует уточнения.

> Фотографии частично перекрываются и относятся к одному отображённому состоянию, поэтому **не образуют временной ряд**.

## Правила работы с документами

1. **Датированный документ — снимок на дату.** Не «исправляй» цифры задним числом; при расхождении фиксируй оба значения с датами
2. **Не удаляй** старые версии — они образуют доказательную базу
3. **Новая оценка = новый документ**, не правка старого
4. При цитировании всегда указывай код источника (`[И5, с. 2]`) — это позволяет проследить утверждение до первичного документа
5. Статус доверия документа ограничивает силу вывода: «не протокол испытаний» означает, что документ описывает заявленное, а не проверенное
